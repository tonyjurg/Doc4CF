lex_utf8_etcbc is a node feature assigning a string value to word nodes, representing the pointed form of each word's lexeme. The sources inventory records 406,914 populated word nodes; words without a value have no assignment, not a negative class. Attested frequent values include וְ and לְ. It belongs to the dss-additions feature family, sourced from automatic morphological parsing later corrected by Thijs Amersfoort.
