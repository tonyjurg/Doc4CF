Open questions

These unresolved points may need editorial review before the descriptions are treated as settled.

Show open questions
  • {docBase} in application.configuration.docs.featureBase is undefined, so the absolute feature documentation URL cannot be determined.
  • The webUrl template {webBase}/search#q='<1>' uses an unspecified placeholder convention (<1>); the substituted value is not documented.
  • The link between configured text-format methods (layoutOrig/layoutSource/layoutTrans) and Python functions fmt_layoutOrig/fmt_layoutSource/fmt_layoutTrans is suggested by naming but not explicitly wired in configuration; runtime dispatch is unverified.
  • application.feature_application_links marks many entries uses_this_feature: true, but the inventory does not show how the application consumes these links or which are active at runtime.
  • Feature lang metadata says language is recorded "only if it is not Hebrew" (g=greek, a=aramaic), while lang_etcbc explicitly includes Hebrew; the representation of Hebrew (absent value vs explicit) is not reconciled.
  • writing "hbo" coexists with lang values for Aramaic and Greek and script values paleohebrew/greekcapital; whether hbo describes only the primary writing system is unstated.
  • typeDisplay marks scroll/line/fragment features as "biblical" while the corpus includes non-biblical scrolls; the coverage of non-biblical material by these features is unclear from configuration alone.
