The cltype feature is a node-level annotation in the Nestle 1904 Greek New Testament syntax annotations that classifies clause type. Three values are attested: VerbElided (2100 occurrences), Verbless (1922), and Minor (1664). The feature is sourced from clause (2718), sentence (125), and wg (2843) nodes. Representative examples include node 138131 ('Ἰωσὴφ υἱὸς Δαυείδ,') annotated Minor, node 138109 ('Πᾶσαι αἱ γενεαὶ...') annotated Verbless, and node 138184 ('πᾶσα Ἱεροσόλυμα μετ’ αὐτοῦ,') annotated VerbElided. The semantic distinction between cltype and clausetype is unspecified, and value definitions are tentative.
