The feature `clausetype` annotates clause type on syntactic constituents in the Nestle 1904 Greek New Testament. It is a node feature with a single observed value, `nominalized`, occurring 10,592 times across clause (5,237), sentence (59), and wg (5,296) nodes. A representative instance is clause node 138106: “ἐξ ἧς ἐγεννήθη Ἰησοῦς ὁ λεγόμενος Χριστός.” The feature’s relationship to `cltype`, which is also described as clause type but uses a different value set (VerbElided, Verbless, Minor), is undocumented. Because only one value is attested, the intended semantic range of `clausetype` remains tentative.
