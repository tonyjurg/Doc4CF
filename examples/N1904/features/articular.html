The node feature articular indicates whether a syntactic constituent has an article. It is attested on clause, group, phrase, sentence, subphrase, and wg nodes; value 1 marks presence of an article. In the Nestle 1904 Greek New Testament, 57,544 nodes carry value 1: clause 3,386; group 181; phrase 13,079; sentence 229; subphrase 11,897; wg 28,772. A representative example is clause node 138107, 'ὁ λεγόμενος Χριστός.' (value 1). Although described as a binary indicator, the inventory attests only value 1; whether value 0 is explicitly stored or absent remains unresolved.
