The node feature appositioncontainer marks whether a syntactic constituent functions as an apposition container in the Nestle 1904 Greek New Testament syntax annotation. It is binary in intent: value 1 indicates that the node is an apposition container. In the corpus, 3,816 nodes carry value 1, distributed across clause (62), phrase (715), subphrase (1,131), and wg (1,908) nodes; no other distinct value is attested. An example is clause node 138132, 'Ἰωσὴφ υἱὸς Δαυείδ,'. The criteria for container status and the treatment of non-containers are not further specified.
