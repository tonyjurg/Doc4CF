Open questions

These unresolved points may need editorial review before the descriptions are treated as settled.

Show open questions
  • lang value el on book nodes may conflict with declared writing system grc; relationship between language code and writing system is not explained.
  • Multiple word-text features overlap (text, unicode, normalized, translit, unaccent); the inventory does not explicitly designate a single primary surface-text convention beyond feature descriptions.
  • Punctuation/material features overlap (before, after, trailer, criticalsign, punctuation); exact boundaries between them are stated per feature but cross-feature consistency is not verified.
  • clausetype and cltype are both described as clause type with different value sets; their relationship is unclear.
  • cls, sp, typ, and typems have overlapping scopes on clause/phrase/word nodes; precise distinctions are not documented in the inventory.
  • omitted_feature_documentation lists 15 features without provided documentation content; omitted_feature_application_links is true; linked_documentation is empty, so semantic details for those features rely only on metadata stubs.
  • skipped_documentation lists 44 feature docs not included in the inventory; their contents are unavailable.
  • Edge features (frame, oSlots, parent, subjref) provide source/target counts but do not fully specify edge directionality or semantics.
  • nodeid is observed only on sentence, clause, and wg nodes despite being described as an XML node ID; coverage on other node types is absent from observed_node_types.
  • verse distinct_values is 81 despite 7,944 verse nodes; the counting granularity for distinct verse values is unclear.
  • dataSource and converterSourceLocation URLs appear in feature metadata but are not independently verified by the inventory.
