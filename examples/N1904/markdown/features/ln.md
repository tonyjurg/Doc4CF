## Reviewed description

The ln feature records Louw–Nida semantic-domain classifications. Values are strings and may contain several space-separated codes, so equality tests and code-membership tests answer different questions. For word counts, restrict the selection to word nodes: this corpus also records ln on phrases and subphrases.

Editorial clarification: [pinned N1904 Louw–Nida tutorial](https://github.com/CenterBLC/N1904/blob/3f53a5a9075cbca5c3001a000a7b004cdee251b6/docs/tutorial/louw-nida.ipynb).
