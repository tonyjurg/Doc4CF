## Generated description

The lemma feature records lexical lemmas as string values on word, phrase, and subphrase nodes in the Greek New Testament \(Nestle 1904\) corpus\. An observed value is ὁ\. Missing assignments mean no value is recorded, not a negative class\. The feature is used in the lex\-orig\-plain text format template \{lemma\}\{trailer\}\.
