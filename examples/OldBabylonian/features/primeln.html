The primeln feature is a node-level attribute on line nodes in the AbB Old Babylonian Cuneiform corpus. It records whether a prime mark is present on a line number. The feature has a single distinct observed value, 1, which occurs on 1,825 line nodes. Because only one value is attested, the inventory does not show how primeln represents the absence of a prime or how it relates to primecol, which marks primes on column numbers.\n
