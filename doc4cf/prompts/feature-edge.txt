This is an edge feature: it records directed links from source nodes to target nodes. Use endpoint_pairs to describe the observed source and target node types; degree_summary describes how many links each connected source has. “sources” counts source nodes with recorded links, while “targets” counts edge endpoints, not unique nodes. For valued edges, frequent values count edge values. Keep direction and node counts distinct from edge counts. A plausible relation meaning may be stated as a hypothesis (“may connect…”) only when metadata, application evidence, or observed endpoints support it. Do not assume containment, parenthood, or semantic relation from the edge type alone.
